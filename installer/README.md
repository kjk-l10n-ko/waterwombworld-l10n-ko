# Water Womb World 한글 패치 (v1.2S) (2026-10-28)

게임 **Water Womb World**(Steam)의 비공식 한글 패치입니다.

* 검수: 김작가
* 작업/번역: Claude Sonnet 5.5/Deepseek v4 flash
* 오류, 오타는 kimjakka96@gmail.com로 제보해주시면 수정 배포하도록 하겠습니다.

## 설정 방법

설정이 필요 없습니다. 설치 후 게임을 실행하면 바로 적용됩니다.

## 패치 내용

* 게임 UI 문장 번역
* 한글 폰트 적용 (영문·숫자 포함 폰트 통일)
* 스토리·인게임 대사 번역

게임 파일은 포함되어 있지 않으며, 사용자의 원본 `data.win`에 변경분만 적용합니다. 원본 파일은 게임 폴더의 `kor_bak` 폴더에 백업됩니다.

* 게임의 저작권은 개발사 및 배급사 등 원 권리자에게 있으며, 본 패치는 공식과 무관합니다.
